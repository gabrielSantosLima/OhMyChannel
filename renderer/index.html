Setup

OhMyChannel uses your own Google Cloud OAuth credentials. Follow the steps below to create them and import the JSON file. No credentials are bundled with the app.

  1. Create a Google Cloud project Open the console and create a new project (or select an existing one).
  2. Enable the YouTube Data API v3 In APIs & Services, open the Library, find and enable the YouTube Data API v3.
  3. Configure the OAuth consent screen Under Google Auth Platform, set the app name and support email, choose External, and add your Google account as a Test user.
  4. Add the required scopes Add https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.force-ssl.
  5. Create a Desktop OAuth client Create an OAuth client of type Desktop app and download the JSON file (the client secret is shown only once).
  6. Import the JSON in OhMyChannel Use the button below to import the downloaded client_secrets.json. It is stored locally in your user data folder.
  7. Sign in with Google Go back to Uploads and click "Sign in with Google" to grant access.

Official docs: OAuth for desktop apps · YouTube Data API getting started · OAuth consent setup · Client secret visibility

Note: while your app is in "Testing", refresh tokens expire in about 7 days. Publish the app or use a Workspace internal project for long-term use.
